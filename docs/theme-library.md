# 主题库、安全导入与回滚

主题库位于“系统设置 → 管理主题库”。导入只注册本地主题，不自动启用；预览保存在当前登录会话，15 分钟后过期；只有用户点击“明确启用”并再次通过完整校验后，系统才同时更新活动主题与 last-known-good。

## 安全导入流程

```text
上传 ZIP
→ 受限临时目录
→ ZIP 数量、大小、算法和压缩比检查
→ 路径、重复名、包装层、符号链接和特殊文件检查
→ 逐条流式解压
→ UTF-8、图片、WOFF2、清单、哈希、配置和 Safe CSS 深度校验
→ 同文件系统原子发布
→ 注册为未启用主题
```

默认限制为上传 12 MiB、解压总量 20 MiB、最多 64 个文件、单条压缩比不超过 100、单张图片不超过 1600 万像素。只允许 Stored 和 Deflate ZIP 条目；不允许加密条目、绝对路径、`..`、Windows 驱动器路径、反斜杠路径、Unicode 非规范名、大小写冲突、符号链接、嵌套包装层、动画图片、伪造图片/字体和未登记资源。

图片使用 Pillow 解码、格式核对、像素限制、`verify()` 与完整加载双重检查。WOFF2 使用 fontTools 完整解析，并要求 `cmap`、`head`、`maxp` 和 `name` 基础表。主题格式继续由 `docs/theme-package-contract.md` 约束，不允许脚本、Django 模板、Python、命令或远程 URL。

## 冲突与原子性

- 相同 ID、相同清单修订值视为已安装，不重复写入；
- 相同 ID、不同内容拒绝，不覆盖内置或运行时目录；
- 发布失败只清理临时目录，不留下部分主题；
- 删除先原子移动到受控隔离名，再清理；清理失败会恢复原目录；
- 内置、活动、last-known-good 和正在预览的主题不可删除。

运行时主题存储在 `THEME_RUNTIME_DIR`，不进入 `.pfbackup`。开发模式只从固定 `/themes/` 路径提供该目录；生产环境由 Caddy 的只读挂载提供，具体配置见 `docs/deployment.md`。

## 回滚

主题选择仍遵循“活动主题 → last-known-good → safe-default”。管理页提供“一键恢复安全默认”。启用主题使用数据库行锁，启用前重新解析清单、资源哈希、结构化配置和 Safe CSS；任一步骤失败都不修改当前主题或 last-known-good。

审计日志只记录操作类型、结果、规范化主题 ID 和错误分类，不记录上传文件名、本机路径、主题内容或用户文件路径。
