# 视觉主题质量基线

本文档固定 `VISUAL-THEME-07` 的自动门槛、人工视口矩阵和视觉回归检查方法。主题只改变表现；财务金额、字段名、表单提交目标和权限边界必须在主题切换前后保持一致。

## 自动门槛

运行：

```powershell
.venv\Scripts\python.exe -m pytest apps/core/tests/test_visual_quality.py -q
```

自动检查包括：

- `safe-default` 与 `aurora-ledger` 的正文、次要正文和强调按钮颜色组合达到 WCAG AA 4.5:1；
- 所有数据表均位于具名、可键盘聚焦的横向滚动区域；
- 跳转链接、主要内容锚点、表单错误、消息和图表替代表格的语义契约；
- 浏览器减少动效、用户减少动效与 Windows 强制颜色回退；
- 两个内置主题全部文件合计小于 80 KiB，沉浸式背景小于 48 KiB、预览图小于 16 KiB、应用组件 CSS 小于 32 KiB；
- 切换主题后关键金额、设置字段名和表单提交目标完全一致；
- 每个页面模板保持一个语义 `h1`。

ECharts 仅在报表页按需加载，不计入全站首次冷加载；其生产缓存策略在 `VISUAL-THEME-08` 验收。

## 视觉回归矩阵

基准浏览器使用 Codex 内置 Chromium。每次改变组件契约、基础 CSS、内置主题或导航结构后，至少重新检查以下矩阵：

| 主题 | 外观 | 视口 | 页面 |
| --- | --- | --- | --- |
| Aurora Ledger | 深色、背景开 | 1440×900 | 登录、首页、交易、预算、报表、主题库、设置 |
| Aurora Ledger | 浅色、背景开 | 1440×900 | 首页、报表、主题库 |
| Aurora Ledger | 深色、背景关 | 390×844 | 首页、交易、表单、主题库 |
| Safe Default | 浅色 | 1440×900 | 登录、首页、交易、报表、主题库 |
| Safe Default | 浅色 | 390×844 | 首页、交易、表单、主题库 |

人工检查必须确认：

- 没有页面级横向溢出，宽表只在自己的具名区域滚动；
- 侧栏与移动导航不会遮挡标题、消息、表单或危险操作；
- `Tab` 顺序从跳转链接进入导航、主内容和操作；所有焦点均可见；
- 收入、支出、风险、成功、警告和危险状态同时具有文字或符号，不只依赖颜色；
- 图表拥有读屏名称并紧邻等价数据表；禁用 JavaScript 后仍可读数据；
- 开启系统或用户“减少动效”后，状态脉冲、悬浮位移和过渡不会持续播放；
- 主题样式、背景或预览图返回 404 时，基础组件 CSS 仍能支撑阅读和核心提交；
- 首次加载和模拟慢速网络中，内容先于装饰资源可用，背景不会造成布局偏移。

## 2026-08-04 基线结果

- Chromium 1440×900 与 390×844：上述主要页面在两个内置主题下无关键遮挡；手机端数据表局部滚动。
- 键盘：跳转链接可将焦点送入 `#main-content`；移动导航、主题预览、启用、恢复和表单提交均可用键盘完成。
- 主题预览：会话横幅可读且可结束，预览不改变活动主题或 last-known-good。
- 资源失败：移除主题选择或请求不存在资源时，服务端结构和表单契约保持可用；运行时选择器回退安全默认主题。
- 资源预算：Aurora 背景 33,312 bytes，预览 8,558 bytes；两个内置主题合计低于 80 KiB。

若矩阵任一项失败，不得只更新本文件中的结果；应先修复或在对应任务中记录阻塞证据。
