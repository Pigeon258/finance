# Aurora Ledger 极光账境视觉方向

Aurora Ledger 是 Personal Finance 的原创沉浸式内置主题。它使用“深夜账境 + 极光数据流”的抽象语言表达稳定、清晰和面向未来的个人财务管理，不包含人物、品牌、货币符号、第三方字体或外部网络资源。

## 视觉系统

- 主色：午夜蓝 `#080d21`，保证长时间查看的低眩光背景；
- 强调色：极光青 `#65e6cf`，用于主要操作、链接与安全状态；
- 辅色：冷蓝 `#7fcfff`、柔紫 `#9b82ff`、琥珀 `#f0c56a` 和风险粉红 `#ff8398`；
- 字体：只使用系统可用的 Segoe UI Variable、Segoe UI、Microsoft YaHei UI 和 system-ui；
- 组件：半透明分层面板、细边框、柔和阴影和圆角形成空间层级；
- 状态：安全、提醒、危险仍保留明确文字，并增加独立颜色、边框和背景；
- 动效：仅状态连接点使用低频脉冲，系统或用户减少动效时降至近零时长。

主题同时提供深色和浅色令牌。`auto` 使用主题深色方向；用户选择浅色时切换为雾蓝玻璃面板和深色文字。关闭背景后改用纯渐变，不加载或显示背景图。

## 背景构图

背景焦点为 `(0.82, 0.24)`，左侧 24% 保持低亮度作为桌面导航安全区；主要极光位于右上区域，中央下部减少高频细节，为表格、表单和数字面板留出可读空间。手机端沿用中央裁切，但所有内容面板维持高不透明度。

首页、登录页可完整展示背景；交易、预算、信用卡、分期、导入、报表、风险和设置页通过内容面板与组件表面降低干扰。宽表始终放入局部横向滚动容器，不扩大手机页面宽度。

## 图表

ECharts 使用与主题一致的五色序列、透明画布、低对比网格线和高对比文本。图表主题通过结构化 JSON 输出，不添加主题 JavaScript，也不改变报表数据与 Decimal 计算。
