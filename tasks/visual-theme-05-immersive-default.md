# VISUAL-THEME-05 沉浸式内置主题

## 目标

基于主题运行时交付一个原创、高完成度的沉浸式默认主题，使主要页面的视觉层次和完整度达到既定参考目标。

## 依赖

`VISUAL-THEME-04`

## 范围

- 确定原创视觉方向、色板、字体、背景、装饰语言和状态动效。
- 为首页、交易、预算、信用卡、分期、导入、报表、风险、设置和登录页制作统一主题。
- 设计桌面背景焦点、安全区域、遮罩和信息密集页面的低干扰模式。
- 提供完整 ECharts 主题和财务状态视觉。
- 保存所有资产来源、许可和可再分发证明。

## 不包含内容

- 不复制 Codex Dream Skin 的人物、品牌或受版权保护素材。
- 不为视觉效果隐藏金额、风险、确认步骤或错误信息。
- 不改变模板中的业务语义。

## 测试要求

- 在既定桌面与窄屏视口完成全部主要页面截图检查。
- 验证浅色、暗色、背景关闭和减少动效模式。
- 验证图表、表格、表单、长文本、空状态、错误和危险操作。

## 完成标准

- 主题不是简单换色，而是覆盖壳层、背景、组件、状态和图表的完整视觉系统。
- 信息密集页面保持可读，主要操作清晰，手机端不溢出。
- 主题包通过 `VISUAL-THEME-04` 的全部校验。
