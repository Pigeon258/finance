# VISUAL-THEME-01 视觉主题需求基线

## 目标

把“页面视觉优化”从主观愿望转换为可验收需求，明确沉浸式主题、组件换肤、主题管理、安全回退和非功能门槛。

## 参考目标

- 视觉完成度参考 Codex Dream Skin 展示的全界面换肤、背景艺术、动态状态和主题管理能力。
- 只参考能力与完成度，不复制未获授权的代码、图片、字体、角色、商标或其他素材。
- Personal Finance 继续使用 Django 服务端渲染，不采用客户端注入方案。

## 范围

- 更新 `docs/requirements.md` 版本和适用范围。
- 新增 `FR-THEME-*`、主题管理页面、文件安全、可用性、备份和验收要求。
- 固化主题只改变展示、不改变财务事实和权限边界。
- 固化无 HTMX、无 JavaScript 和主题资源失败时的核心流程可用性。

## 不包含内容

- 不实现主题代码、视觉稿、主题包导入或页面重构。
- 不选择具体原创主题素材。
- 不修改任何账务计算口径。

## 验收要求

- 需求覆盖设计系统、默认主题、主题包、预览切换、回退、图表、响应式和无障碍。
- 需求明确禁止任意 Python、Django 模板、JavaScript、系统命令和远程代码。
- 主题偏好与主题资产在业务备份中的边界明确。
- 后续任务可逐项引用稳定的 `FR-THEME-*` 编号。
