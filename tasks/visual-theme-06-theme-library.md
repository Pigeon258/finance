# VISUAL-THEME-06 主题库、安全导入与回滚

## 目标

为单用户提供可审计的主题管理体验，安全完成 ZIP 导入、预览、启用、停用、删除和失败回滚。

## 依赖

`VISUAL-THEME-04`、`VISUAL-THEME-05`

## 范围

- 实现主题管理页面和系统设置入口。
- 实现 ZIP 隔离、限额、路径、类型、清单、哈希、图片、字体和 Safe CSS 校验。
- 原子安装到受控主题库，不覆盖已有活动目录。
- 实现预览会话、明确启用、停用、删除保护和 last-known-good 回滚。
- 如确有查询和审计消费者，再引入最小 `InstalledTheme` 模型及同任务迁移。
- 记录非敏感操作结果，不记录主题文件内容或用户路径。

## 不包含内容

- 不建立在线主题商店、自动下载、自动更新或远程安装协议。
- 不允许主题包含脚本、模板、系统命令或外部 URL。
- 不把主题资产打入 `.pfbackup`。

## 测试要求

- ZIP 正向、重复、冲突、超限、炸弹、穿越、链接、嵌套包和伪造类型测试。
- 导入中断、磁盘写入失败、并发启用和删除保护测试。
- 未登录访问、CSRF、CSP、日志脱敏和主题目录越权读取测试。

## 完成标准

- 导入只进入主题库，不自动改变活动主题。
- 任意失败不会留下部分目录或损坏当前主题。
- 用户可一键恢复安全默认主题。
