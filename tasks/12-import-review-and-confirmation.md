# 12 导入映射、去重与幂等确认

## 目标

将待确认记录经账户映射、分类推荐、重复处理和人工确认安全地转成正式账本事实。

## 范围

- `ImportDuplicateCandidate`、`MerchantCategoryRule`、`ImportAccountRule`。
- 账户映射和分类推荐优先级、批量修改。
- 外部流水号、标准指纹、手动交易模糊匹配四层去重。
- 保留手动、使用导入替换、两条保留、合并信息的处理结果。
- 每批最多 500 条的原子、行锁、状态复核和幂等确认。

## 不包含内容

- AI 分类、银行卡/信用卡解析、自动删除疑似重复、异步队列。

## 涉及模块

`imports` 调用 `ledger.services`；读取 `accounts`，不得直接写账本模型。

## 主要数据模型或接口

- 设计第 29～32、52 节约束和索引。
- 对 source + external ID 的唯一保护应落在可跨批次防重复的位置，并用 DB 约束证明。

## 实施步骤

1. 建模规则和候选，固化优先级与启停。
2. 实现外部 ID、指纹和模糊评分；疑似项只标记。
3. 实现待确认编辑、批量分类/账户/忽略和重复决策。
4. 在 `atomic + select_for_update` 中重新去重并调用账本服务。
5. 实现退款关联建议及合法退款确认。

## 测试要求

- 精确重复跨批次禁止；模糊阈值 69/70/84/85 边界。
- 批量 500/501、任一失败整批回滚、双击和并发确认不重复。
- 解析记录与正式交易一对一；未确认记录不进账本。
- 规则优先级、停用、账户未知和退款候选。

## 完成标准

- FR-IMP 与 FR-CAT 的 P0/P1 条目完成，重复由用户决定且数据库最终兜底。
- 导入结果与手工记账使用同一账本服务和不变量测试。
