# VISUAL-THEME-03 视觉设计系统与组件契约

## 目标

把当前分散、简陋的页面结构重构为一致、语义清晰且可稳定换肤的服务端组件系统，同时保留全部核心流程。

## 依赖

`VISUAL-THEME-02`

## 范围

- 本地引入并固定 Bootstrap 5，建立应用级设计令牌和组件映射。
- 重构 `base.html`、导航、消息、页面标题、卡片、按钮、表单、表格、状态、空状态和图表容器。
- 为注册组件增加 `data-pf-part`，并建立组件模板或可复用 partial。
- 统一所有现有页面的结构和无 JavaScript 降级表现。
- 提供不可删除、低风险的 `safe-default` 主题。

## 不包含内容

- 不实现 ZIP 导入和第三方 Safe CSS。
- 不制作最终沉浸式主题素材。
- 不改变 URL、视图权限、表单字段和业务服务。

## 测试要求

- 现有视图、表单和业务集成测试保持通过。
- 增加组件契约、导航、消息和无 JavaScript 核心流程测试。
- 对所有主要模板扫描禁止未迁移的关键裸组件结构。
- 使用 `powershell.exe` 运行任务指定的 Windows 验证入口。

## 完成标准

- 所有主要页面采用一致组件系统。
- 注册部件具有稳定名称和文档。
- `safe-default` 在样式加载失败时仍保持可读可操作。
